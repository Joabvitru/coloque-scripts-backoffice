# Scripts backoffice

Página com os scripts de resposta do atendimento ao aluno.

- `index.html`: a página.
- `scripts.json`: todos os scripts. É alterado pela própria página, no modo edição (botão da chave).

Para editar, a pessoa precisa ser colaboradora deste repositório e entrar no modo edição com um token do GitHub (as instruções aparecem na página).
